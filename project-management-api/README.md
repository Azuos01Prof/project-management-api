# Project Management API

A robust REST API for project management with JWT authentication, role-based authorization, and external weather API integration.

## Features

- ✅ JWT Authentication
- ✅ Role-based Authorization (Admin/User)
- ✅ Project CRUD Operations
- ✅ External Weather API Integration
- ✅ Error Handling & Validation
- ✅ Comprehensive Test Suite

## Technologies

- Node.js
- Express.js
- JWT (JSON Web Tokens)
- Axios (HTTP Client)
- OpenWeather API
